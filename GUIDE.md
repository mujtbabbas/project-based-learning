# Reader's Guide — project-based-learning

## What this project is

**Project Based Learning** is a list of **programming tutorials in which you
learn by building a complete application from scratch** — the antidote to
tutorial fragments. Every entry is a guided build of a real thing (an app, a
game, a tool, a clone), chosen so an aspiring developer finishes with both a
working project and the understanding that only building gives.

## How the content is organised

Everything lives in [`README.md`](README.md), divided **by primary
programming language** — find your language in the Table of Contents:

C/C++ · C# · Clojure · Dart · Elixir · Erlang · F# · Java · JavaScript ·
HTML and CSS · Kotlin · Lua · Python · Go · PHP · OCaml · Ruby · Haskell ·
R · Rust · Scala · Swift

— followed by **Additional Resources** for material that is not tied to one
language. Within each language section, entries are tutorial links with short
descriptions; a tutorial may involve several technologies even though it is
filed under its primary language.

Supporting files: `CONTRIBUTING.md` — how tutorials are proposed and the
quality bar (a real build, from scratch, not a snippet); `scripts/` — the
repository's maintenance scripts (the README carries a "link rot sweep" badge
for the checks that keep thousands of outbound links honest); `LICENSE.md` —
MIT.

## How to use it

1. Pick the language you are learning from the Table of Contents.
2. Choose a tutorial whose end product interests you — motivation matters
   more than the specific stack.
3. Build the whole thing, start to finish; then build a variation of your own
   without the guide.
